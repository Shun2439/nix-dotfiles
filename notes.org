** Btrfs
#+begin_src nix
services.btrfs.autoScrub = {
  enable = true;
  interval = "weekly";
  fileSystems = [ "/" ]; # Btrfsのルートを指定
};
#+end_src
:LOGBOOK:
- Note taken on [2026-11-03 火 14:01] \\
  autoScrub + compress を実際に導入した。以下はその記録。
:END:

*** 現状
- Btrfs なのは manaslu だけ（kilimanjaro は ext4）。manaslu の ~/~ は ~nvme0n1p5[/@]~、サブボリュームは ~@~ の 1 個だけ
- docker は ~storageDriver = "btrfs"~ で稼働中
- swap は ~/var/lib/swapfile~ (4GB) + zram 25% で構成済み
*** 追加した設定
- ~services.btrfs.autoScrub~ → [[file:systems/nixos/manaslu/default.nix][default.nix]]
  ~fileSystems~ はデフォルトが ~[ "/" ]~ なので省略
- ~compress=zstd:3~ → [[file:systems/nixos/manaslu/hardware-configuration.nix][hardware-configuration.nix]] の ~fileSystems."/".options~
*** ハマりどころ
- ~chattr~ / ~lsattr~ は NixOS の system PATH に無く、~sudo~ は PATH をリセットするので
  store のパスを直接叩く（恒久対策は ~environment.systemPackages~ に ~e2fsprogs~ ）
  #+begin_src shell
  sudo /nix/store/ja4ggh64fjyja45f6jarz5iaq2fr3n8d-e2fsprogs-1.47.4-bin/bin/chattr +C /var/lib/swapfile
  sudo "$(nix build --no-link --print-out-paths nixpkgs#e2fsprogs)/bin/chattr" +C /var/lib/swapfile
  #+end_src
  swapfile が圧縮されると ~swapon~ が失敗するため ~+C~ (COW/圧縮無効) を付ける。起動は継続するので致命傷にはならない
- 圧縮はマウント時に効くので *再起動後* から。 ~nixos-rebuild switch~ では反映されない
  （即時反映は ~sudo mount -o remount,compress=zstd:3 /~ ）
- 既存ファイルは遡って圧縮されない。 ~defragment -czstd~ で回収できるが、
  スナップショットの共有を壊すので原則やらない
- 確認: ~findmnt -no OPTIONS /~ / ~systemctl list-timers | grep btrfs~
*** 見送ったもの
- snapper などのスナップショット: ブートローダが systemd-boot なので ~grub-btrfs~ の
  起動メニュー統合が使えない。システム復旧は NixOS の世代ロールバックで足りる。
  ~/home~ の事故対策はスナップショットより外部バックアップ (restic 等) の方が本質的
- サブボリューム分割 (~@home~ / ~@nix~): スナップショットを取らないなら意味が薄く、データ移行も重い
- ~noatime~ （ ~relatime~ で誤差）、quota group（遅くなる）

*** Switch modes
#+begin_src shell
warp-cli mode --help
#+end_src

- ~warp-cli mode warp~ :: トンネルを確立し、通常の UDP DNS プロキシを使用する
- ~warp-cli mode doh~ :: トンネルを確立しない。DoH 上でプロキシ DNS のみを使用する。
- ~warp-cli mode warp+doh~ :: トンネルを確立し、DNS に DoH を使用する。
- ~warp-cli mode dot~ :: トンネルを確立しないでください。DoT 上でプロキシ DNS のみを使用してください。
- ~warp-cli mode warp + dot~ :: トンネルを確立し、DNS に DoT を使用する。
- ~warp-cli mode proxy~ :: SOCKS5 プロキシで使用するためのトンネルを確立する。
- ~warp-cli mode tunnel_only~ :: トンネルを確立し、DNS プロキシを使用しない。
